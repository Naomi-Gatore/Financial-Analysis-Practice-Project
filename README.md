# Financial Analysis Practice Project

A collection of Python financial analysis projects 
analyzing Microsoft and Facebook stock data.

# Projects:
1. 01-financial-analysis-practice - Financial Analysis 
   and Trading Strategy using Moving Averages
2. 02-regression-analysis - Regression Analysis 
   on Stock Data
3. 03-predictive-modeling - Predictive Modeling 
   using Machine Learning
4. 04-final-project - Final Comprehensive 
   Financial Analysis Project

# Tools Used:
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
